# SkillMatch – AI Resume Screener and Job Matcher

SkillMatch is a full-stack web application that helps job seekers match their resumes against job descriptions using AI-powered analysis.

## Tech Stack

- **Frontend:** React.js + Vite + Tailwind CSS
- **Backend:** FastAPI (Python)
- **Database:** MongoDB Atlas
- **Authentication:** JWT (planned)
- **Version Control:** Git & GitHub
